Política de Privacidade

Última atualização: 13 de novembro de 2026

Esta política descreve como o aplicativo “cortes”, ferramenta interna do canal Civitas Forum, trata os dados obtidos por meio das APIs do Google e do YouTube.

Quem usa o aplicativo

O aplicativo é usado exclusivamente pelo administrador do canal Civitas Forum, no próprio computador, para gerenciar o próprio canal. Ele não é distribuído nem oferecido a outras pessoas.

Dados acessados

Com a autorização do dono do canal, o aplicativo usa a YouTube Data API v3 com as permissões:

  • youtube.upload: para enviar e agendar vídeos no canal autorizado;
  • youtube.readonly: para ler dados dos vídeos do próprio canal (título, status de publicação, visualizações, curtidas e número de comentários).

O aplicativo não lê o conteúdo de comentários, não acessa dados de espectadores, inscritos ou outros canais, e não pede acesso a e-mail, contatos ou qualquer outro dado da Conta do Google.

Como os dados são usados e guardados

  • As estatísticas dos vídeos são usadas apenas para avaliar quais vídeos do canal performam melhor e orientar a escolha dos próximos cortes.
  • O token de autorização e as estatísticas ficam armazenados somente no computador do administrador do canal, protegidos por permissões de arquivo. Não existe servidor ou banco de dados na nuvem.
  • Os dados não são vendidos, compartilhados, transferidos a terceiros nem usados para publicidade.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O aplicativo também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token deixa de funcionar; os dados guardados localmente podem ser apagados excluindo a pasta do canal no computador.

Contato

Dúvidas sobre esta política podem ser enviadas pelo canal Civitas Forum no YouTube.
